## Description

Authorization checks are performed but incorrectly implemented. CWE-863 ranked #17.

## Impact

Partial access control bypass allowing unintended operations.

## Mitigation

Centralized policy engine; test all roles; code review auth logic; deny by default.

## Replication Steps

1. Define role matrix.
2. Test edge cases (HTTP method tampering, parameter pollution).
3. Find operations allowed despite policy intent.
4. Document flawed check location.
5. Capture unauthorized success.
