## Description

Application allows steps to be performed out of intended order. Mapped under A06:2025.

## Impact

Bypass of payment, approval, or multi-step security workflows.

## Mitigation

Server-side state machine; validate prior steps completed; signed workflow tokens.

## Replication Steps

1. Map multi-step process.
2. Skip steps via direct URL/API calls.
3. Complete action without prerequisites.
4. Document bypass.
5. Capture evidence.
