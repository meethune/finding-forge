## Description

Authentication mechanism can be bypassed or is logically flawed. Mapped under A07:2025.

## Impact

Account access without valid credentials.

## Mitigation

Review auth design; MFA; secure frameworks; penetration test all auth paths.

## Replication Steps

1. Map authentication entry points.
2. Test alternate channels and parameter manipulation.
3. Attempt bypass of second factor in lab.
4. Document flaw.
5. Capture proof.
