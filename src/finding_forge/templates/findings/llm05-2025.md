## Description

Insufficient validation of LLM outputs before use in downstream systems (SQL, shell, HTML, APIs) enables injection and XSS in consuming applications.

## Impact

LLM output treated as trusted can cause traditional injection in browsers, databases, or orchestration layers.

## Mitigation

Treat LLM output as untrusted input; encode/validate per downstream context; allowlists for actions; sandbox tool execution.

## Replication Steps

1. Cause model to emit payloads for target interpreters.
2. Observe whether application executes or renders output unsafely.
3. Test chained tool calls with malicious model suggestions.
4. Document downstream sinks without sanitization.
5. Capture end-to-end exploit path.
