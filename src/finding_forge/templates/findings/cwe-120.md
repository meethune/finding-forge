## Description

Copying data into a buffer without verifying size. CWE-120 re-entered Top 25 in 2025.

## Impact

Memory corruption and potential RCE in native components.

## Mitigation

Safe string functions; compile with stack protections; migrate to memory-safe code.

## Replication Steps

1. Identify fixed-size buffers in native code paths.
2. Fuzz with oversized input.
3. Analyze crashes.
4. Map to CVEs.
5. Recommend patches.

## Detection

**Host:** Stack overflow exceptions; DEP violations.

## Guidance

Group with CWE-787, CWE-121, CWE-122 for reporting.
