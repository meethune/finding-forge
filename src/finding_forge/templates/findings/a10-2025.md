## Description

New in OWASP Top 10:2025. Covers improper error handling, failing open, uncaught exceptions, and unpredictable application state under abnormal conditions—often enabling logic bugs, information disclosure, or DoS.

## Impact

May leak stack traces and secrets, leave partial transactions committed, exhaust resources, or allow security controls to be bypassed when errors are not handled fail-closed.

## Mitigation

Catch exceptions at source; fail closed on transactions; global exception handler; rate limiting; avoid verbose errors to users; centralized error handling; input validation; monitor repeated errors.

## Replication Steps

1. Send malformed, missing, and out-of-range parameters.
2. Interrupt long-running operations (network drop mid-transaction).
3. Observe error messages and application state after failures.
4. Test resource exhaustion under repeated errors.
5. Verify transactional rollback behavior.
