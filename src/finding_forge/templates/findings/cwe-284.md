## Description

Access control policy is not properly enforced. CWE-284 ranked #19 (new to Top 25).

## Impact

Unauthorized data access or privilege escalation.

## Mitigation

Implement consistent access control model; test all roles; server-side enforcement.

## Replication Steps

1. Test horizontal and vertical access.
2. Compare with policy documentation.
3. Document gaps.
4. Capture evidence.
5. Map to affected assets.
