## Description

Uncontrolled resource use (tokens, GPU, API calls) enables DoS and cost exhaustion attacks against LLM services.

## Impact

Service degradation, financial loss from cloud bills, and denial of service to legitimate users.

## Mitigation

Rate limits; quotas per user/tenant; request size caps; timeouts; cost monitoring and alerts; caching where appropriate.

## Replication Steps

1. Send high-volume or maximal-length prompts.
2. Trigger expensive tool or retrieval loops.
3. Measure latency, billing impact, and throttling behavior.
4. Verify account-level limits.
5. Document absence of controls.
