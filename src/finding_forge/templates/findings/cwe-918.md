## Description

The server fetches URLs supplied by users, enabling access to internal services or cloud metadata. CWE-918 ranked #22.

## Impact

Internal network reconnaissance, cloud credential theft (IMDS), and bypass of network controls.

## Mitigation

Allowlist destinations; block link-local and private IPs; disable unnecessary URL schemes; network segmentation.

## Replication Steps

1. Identify URL parameters processed server-side.
2. Request internal addresses and cloud metadata endpoints.
3. Observe response or out-of-band hits.
4. Document reachable internal resources.
5. Assess blast radius.

## Detection

**Network:** Egress to RFC1918, 169.254.169.254, or unusual internal ports from app servers.

## Guidance

Parent: A01:2025. Critical when cloud metadata or internal admin reachable.
