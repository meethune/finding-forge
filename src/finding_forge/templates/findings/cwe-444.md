## Description

Discrepant parsing between front-end and back-end servers enables request smuggling. Mapped under A06:2025.

## Impact

Cache poisoning, bypass of security controls, request hijacking.

## Mitigation

Normalize HTTP parsing; patch servers; HTTP/2 end-to-end; disable connection reuse where risky.

## Replication Steps

1. Identify multi-tier HTTP architecture.
2. Use smuggling probes in authorized test.
3. Detect desync behavior.
4. Document affected hops.
5. Recommend vendor patches.

## Detection

**Network:** Abnormal Content-Length vs Transfer-Encoding patterns; desync indicators at proxies.

Advanced finding; requires careful testing scope.
