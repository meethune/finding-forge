## Description

Credentials embedded in source, binaries, or config repositories. Mapped under A07:2025.

## Impact

Full compromise of associated systems; lateral movement when secrets are reused.

## Mitigation

Secret management vault; rotate exposed credentials; scan repos; never commit secrets.

## Replication Steps

1. Review source, mobile apps, and config artifacts.
2. Search for API keys and passwords.
3. Validate discovered credentials safely.
4. Document location and scope.
5. Recommend rotation.
