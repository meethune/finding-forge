## Description

Software writes past the end of a buffer, corrupting memory. Common in native code; CWE-787 ranked #5 with 12 KEV CVEs.

## Impact

Memory corruption leading to crash or arbitrary code execution.

## Mitigation

Memory-safe languages; bounds checking; compiler mitigations (ASLR, DEP, stack canaries); fuzzing; static analysis.

## Replication Steps

1. Identify native attack surface (parsers, protocols).
2. Fuzz with corrupted inputs in lab.
3. Monitor crashes and exploitability.
4. Map to patched CVEs where applicable.
5. Recommend upgrade or virtual patch.
