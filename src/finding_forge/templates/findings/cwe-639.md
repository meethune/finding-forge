## Description

Insecure Direct Object Reference (IDOR)—access control relies on user-supplied keys without server verification. CWE-639 ranked #24 (+6).

## Impact

Horizontal privilege escalation accessing other users' records.

## Mitigation

Server-side authorization per object; unpredictable identifiers; verify ownership on every access.

## Replication Steps

1. Authenticate as User A.
2. Capture object identifiers.
3. Access as User B using A's identifiers.
4. Confirm unauthorized data returned.
5. Document affected objects.
