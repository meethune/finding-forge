## Description

Verbose errors reveal stack traces, queries, or internal paths. Mapped under A10:2025.

## Impact

Information disclosure aiding targeted exploits.

## Mitigation

Generic user errors; log details server-side only; custom error pages.

## Replication Steps

1. Trigger application errors.
2. Review responses for stack traces and queries.
3. Document fields disclosed.
4. Map to endpoints.
5. Recommend safe error handling.
