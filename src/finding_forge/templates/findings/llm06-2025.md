## Description

LLM agents granted excessive autonomy, permissions, or tool access can perform unintended high-impact actions without adequate human oversight.

## Impact

Unauthorized purchases, data deletion, privilege changes, or lateral movement via integrated APIs.

## Mitigation

Least-privilege tools; explicit human-in-the-loop for destructive actions; scope limits; confirm intent for irreversible operations; monitor agent action logs.

## Replication Steps

1. Enumerate tools and APIs available to the agent.
2. Attempt actions beyond stated user intent via prompt injection.
3. Verify approval workflows for sensitive operations.
4. Test permission boundaries between users/tenants.
5. Document excessive or unbounded agency.
