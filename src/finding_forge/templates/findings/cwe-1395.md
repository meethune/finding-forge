## Description

Application depends on libraries or components with known vulnerabilities. Central to OWASP A03:2025.

## Impact

Exploitation of public CVEs against outdated dependencies.

## Mitigation

SBOM; continuous CVE monitoring; risk-based patching; Dependency-Track or OSV scanners in CI/CD.

## Replication Steps

1. Generate dependency inventory from builds and containers.
2. Match versions to CVE databases.
3. Prioritize by CVSS and exposure.
4. Verify compensating controls.
5. Document vulnerable component and fixed version.
