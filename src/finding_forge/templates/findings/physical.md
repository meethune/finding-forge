## Description

Facilities or workspaces allow unauthorized physical access to systems, network ports, or sensitive documents.

## Impact

Direct device compromise, implant installation, and data theft bypassing logical controls.

## Mitigation

Badge access; visitor escorts; secure cabinets; port security; clean desk; surveillance.

## Replication Steps

1. Attempt tailgating and unescorted access per rules of engagement.
2. Inspect unlocked workstations and network ports.
3. Document physical control gaps.
4. Avoid illegal entry beyond scope.
5. Recommend controls.
