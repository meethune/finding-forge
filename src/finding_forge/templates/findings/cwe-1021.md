## Description

Pages can be framed to trick users into clicking hidden UI elements.

## Impact

Unauthorized actions performed by authenticated users via UI redress.

## Mitigation

X-Frame-Options or CSP frame-ancestors; JavaScript frame busting as supplement only.

## Replication Steps

1. Load target page in iframe on attacker page.
2. Overlay deceptive UI.
3. Demonstrate click on sensitive action.
4. Check frame-busting headers.
5. Document missing protections.
