## Description

Authentication failures allow attackers to compromise passwords, session tokens, or bypass authentication entirely. Includes credential stuffing, weak passwords, missing MFA, session fixation, and improper session invalidation.

## Impact

Account takeover enables access to user data and privileged functions. SSO session issues can affect multiple integrated applications.

## Mitigation

Implement MFA; block credential stuffing; no default credentials; strong password policy per NIST 800-63b; secure session management; uniform error messages; rate limit logins; validate JWT iss/aud; use established identity providers.

## Replication Steps

1. Test login, registration, password reset, and MFA flows.
2. Assess session token entropy, transport, and invalidation on logout.
3. Attempt credential stuffing and account enumeration.
4. Review SSO/SLO behavior across integrated apps.
5. Document authentication bypass or session issues.
