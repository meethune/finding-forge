## Description

Program continues to use memory after it has been freed. CWE-416 ranked #7 with 14 KEV CVEs.

## Impact

Memory corruption and reliable exploitation in browsers and native services.

## Mitigation

Memory-safe languages; patch promptly; exploit mitigations; fuzzing.

## Replication Steps

1. Track advisories for affected native components.
2. Verify versions against patched releases.
3. Use vendor PoC only in authorized lab.
4. Document vulnerable build.
5. Recommend upgrade.

## Detection

**Host:** Crash dumps referencing freed regions; exploit detection for UAF primitives.
