## Description

Without sufficient logging, monitoring, and alerting, breaches and attacks may go undetected. Includes missing audit trails, log injection, sensitive data in logs, and absent or ineffective SOC playbooks.

## Impact

Delayed detection increases dwell time, forensic cost, and regulatory impact. Active attacks may persist undetected despite technical exploitability elsewhere.

## Mitigation

Log security-relevant events (auth success/failure, access control denials, high-value transactions); protect log integrity; centralize logs; define alert use cases and playbooks; test that attacks trigger alerts; avoid logging secrets.

## Replication Steps

1. Perform actions that should generate security events (failed login, access denied).
2. Verify events appear in SIEM/log store with correct fields.
3. Confirm no sensitive data is written to logs.
4. Review alerting rules and response playbooks.
5. Note gaps between expected and actual visibility.
