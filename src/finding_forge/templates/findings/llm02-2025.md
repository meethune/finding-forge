## Description

LLMs may reveal PII, credentials, proprietary data, or system prompts through responses, training data memorization, or excessive context retention.

## Impact

Regulatory breach, intellectual property loss, and credential compromise affecting connected systems.

## Mitigation

Data minimization in prompts; redact logs; access controls on vector stores; output filtering; user consent; avoid placing secrets in prompts; monitor for leakage patterns.

## Replication Steps

1. Probe model for training data or context secrets.
2. Test RAG retrieval across tenant boundaries.
3. Review logging and third-party LLM data handling policies.
4. Attempt to extract system prompts.
5. Document disclosed sensitive content.
