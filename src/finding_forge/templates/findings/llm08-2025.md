## Description

RAG vector stores may allow cross-tenant data retrieval, poisoned embeddings, or manipulation of similarity search to surface malicious content.

## Impact

Wrong-tenant retrieval causes data breach; poisoned chunks enable indirect prompt injection.

## Mitigation

Tenant isolation in indexes; access controls; validate embedded content; monitor retrieval quality; sign/hash document sources.

## Replication Steps

1. Test retrieval as one user for another user's documents.
2. Upload content designed to rank highly for others' queries.
3. Review embedding pipeline and access ACLs.
4. Inspect chunking and metadata filters.
5. Document isolation failures.
