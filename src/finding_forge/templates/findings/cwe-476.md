## Description

Dereferencing a NULL pointer causes crash; may be exploitable. CWE-476 ranked #13 (+8 positions).

## Impact

Denial of service; possible exploitation in specific architectures.

## Mitigation

Null checks; static analysis; fuzzing; patch affected libraries.

## Replication Steps

1. Trigger fault via malformed input.
2. Observe crash and exploitability.
3. Verify patch level.
4. Document reproduction.
5. Recommend upgrade.

**Host:** Application crash logs with access violation at low addresses.
