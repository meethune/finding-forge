## Description

Software reads data past buffer boundaries. CWE-125 ranked #8.

## Impact

Information disclosure, crash, or chaining into write primitives.

## Mitigation

Bounds checks; safe string APIs; fuzzing; compiler hardening.

## Replication Steps

1. Fuzz parsers and protocol handlers.
2. Detect crashes or abnormal data leaks.
3. Correlate with CVE advisories.
4. Document affected component version.
5. Recommend remediation.

**Host:** Memory safety crash signatures; ASAN-detected OOB in test builds.
