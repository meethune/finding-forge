## Description

The software does not perform authorization checks before allowing access to resources or functions. CWE-862 rose five positions to #4 in 2025.

## Impact

Unauthorized access to data or administrative capabilities without authentication bypass.

## Mitigation

Enforce authorization on every request server-side; default deny; unit tests for access control matrix.

## Replication Steps

1. Access resources with authenticated but unauthorized roles.
2. Compare access across role matrix.
3. Identify missing server-side checks.
4. Document endpoints lacking authorization.
5. Capture proof of unauthorized operation.
