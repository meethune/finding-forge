## Description

Untrusted serialized objects are deserialized, enabling gadget-chain RCE. CWE-502 ranked #15 with 11 KEV CVEs.

## Impact

Full server compromise via known gadget chains (Java, .NET, Python pickle, etc.).

## Mitigation

Avoid deserializing untrusted data; integrity checks; allowlists; updated libraries; WAF virtual patches.

## Replication Steps

1. Identify serialization formats in transit (base64, rO0, etc.).
2. Use lab tools to test gadget chains.
3. Confirm impact only with authorization.
4. Document library versions.
5. Recommend safe formats (JSON) with schema validation.
