## Description

The application allows upload of executable or dangerous file types without validation. CWE-434 ranked #12.

## Impact

Remote code execution via web shells, stored XSS, or malware hosting.

## Mitigation

Allowlist extensions and MIME; scan uploads; store outside web root; randomize names; disable execution on upload directories.

## Replication Steps

1. Upload test files with dangerous extensions and content-types.
2. Attempt to access uploaded file via URL.
3. Verify execution or serving behavior.
4. Test bypass of client-side filters.
5. Document upload path and permissions.
