## Description

Application fails to regenerate session ID after login. Mapped under A07:2025.

## Impact

Attacker-fixed session ID allows hijack after victim authenticates.

## Mitigation

Regenerate session ID on privilege change; invalidate pre-auth sessions.

## Replication Steps

1. Obtain session ID before login.
2. Trick victim to authenticate with same ID (phishing simulation).
3. Reuse ID to access account.
4. Document session handling.
5. Recommend regeneration.
