## Description

Injection occurs when untrusted input is sent to an interpreter (SQL, OS shell, LDAP, XPath, template engine, browser DOM) without validation or parameterization, causing unintended command execution. Includes XSS as high-frequency injection into HTML contexts.

## Impact

Successful injection can lead to authentication bypass, full database extraction, remote command execution, or session hijacking depending on interpreter and privileges.

## Mitigation

Use parameterized APIs and ORMs; avoid dynamic concatenation; positive input validation; context-specific output encoding; SAST/DAST in CI/CD; least privilege for database and OS accounts.

## Replication Steps

1. Identify all input vectors (parameters, headers, cookies, JSON, file uploads).
2. Submit metacharacters and fuzz payloads per context (SQL, XSS, command).
3. Observe errors, timing, and out-of-band callbacks.
4. Confirm impact with minimal proof (single row, benign command).
5. Capture requests and responses.
