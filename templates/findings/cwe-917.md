## Description

User input embedded in server-side templates leads to code execution in template engine.

## Impact

Remote code execution in web tier.

## Mitigation

Never pass user input to template engines; logicless templates; sandboxing.

## Replication Steps

1. Detect template engine via polyglot probes.
2. Escalate to harmless computation proof.
3. Avoid destructive payloads.
4. Document engine and parameter.
5. Recommend architectural fix.
