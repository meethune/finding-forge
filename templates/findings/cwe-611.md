## Description

XML parsers resolve external entities, enabling file read, SSRF, or DoS. Mapped under A02:2025 Security Misconfiguration.

## Impact

Disclosure of local files, internal port scanning, and denial of service via entity expansion.

## Mitigation

Disable DTDs and external entities; use JSON; patch parser libraries; input validation.

## Replication Steps

1. Submit XML with external entity definitions.
2. Attempt file read or SSRF via entities.
3. Test billion laughs DoS only in lab with approval.
4. Document parser and endpoint.
5. Capture minimal proof.
