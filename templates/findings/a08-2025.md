## Description

Integrity failures occur when code or data is consumed without verifying authenticity—unsigned updates, untrusted CDNs/plugins, insecure CI/CD artifacts, or insecure deserialization treating attacker-controlled data as trusted.

## Impact

Attackers may distribute malicious updates, execute code via deserialization, or hijack sessions via untrusted included scripts.

## Mitigation

Sign software and updates; verify integrity before install; secure CI/CD; avoid deserializing untrusted data; SRI for third-party scripts; review code changes; segregate build environments.

## Replication Steps

1. Review auto-update and plugin inclusion mechanisms.
2. Test deserialization endpoints with safe gadget-chain probes in lab.
3. Assess CI/CD artifact signing and promotion controls.
4. Check third-party script inclusion without integrity attributes.
5. Document integrity verification gaps.
