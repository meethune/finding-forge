## Description

Critical functionality lacks authentication. CWE-306 ranked #21 with 11 KEV CVEs.

## Impact

Unauthenticated administrative or data access.

## Mitigation

Require authentication for all non-public functions; network-layer controls as supplement only.

## Replication Steps

1. Crawl and map endpoints.
2. Access admin or sensitive APIs without credentials.
3. Confirm lack of auth middleware.
4. Document endpoints and impact.
5. Recommend auth enforcement.
