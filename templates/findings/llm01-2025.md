## Description

Prompt injection alters LLM behavior via malicious or unintended instructions in user input or untrusted external content (RAG, web pages, files). Includes direct, indirect, multimodal, and jailbreak variants.

## Impact

May cause data exfiltration, unauthorized tool invocation, privilege escalation in agentic systems, or manipulation of downstream decisions.

## Mitigation

Constrain model behavior; validate outputs; filter inputs/outputs; least-privilege tool access; human approval for high-risk actions; segregate untrusted content; adversarial testing. See MITRE ATLAS AML.T0051.

## Replication Steps

1. Identify LLM entry points (chat, API, RAG ingestion).
2. Inject instructions to override policies (direct injection).
3. Embed instructions in retrieved documents or uploads (indirect).
4. Observe tool calls, data returned, or policy violations.
5. Document successful manipulation with prompts and responses.
