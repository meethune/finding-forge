## Description

Application redirects users to URLs from untrusted input without validation.

## Impact

Phishing using trusted domain; OAuth token theft in some flows.

## Mitigation

Allowlist redirect targets; use indirect references; warn users on external redirect.

## Replication Steps

1. Find redirect parameters (url, next, return).
2. Supply external domain.
3. Confirm 302 to attacker URL.
4. Test bypass encodings.
5. Document parameter.
